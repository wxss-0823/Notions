# Julia Tutorial

## 1. 基本语法

### 1.1. 变量

​	Julia 语言变量名由字母、数字、下划线 `_` 组成，其中首个字符不能为数字。变量名是大小写敏感的。

​	Julia 变量使用很简单，只需要赋值即可。

### 1.2. 命名规范

- 变量名采用小写；
- 使用下划线分隔变量名中的单词；
- 类型 `Type` 和模块 `Module` 的名称使用大写字母开头，并且用大写字母而不是下划线分隔单词；
- 函数（function）和宏（macro）的名字使用小写，不适用下划线；
- 会对输入参数进行更改的函数使用 `!` 结尾，这些函数叫做 “mutating” 或 “in-place” 函数，因为它们在被调用后会修改他们的输入参数的内容而不仅仅只是返回一个值。

### 1.3. 注释

​	Julia 中的注释有单行注释和多行注释。以 `#` 开头，多行注释用 `#=` 和 `=#` 包含起来。

## 2. 数组

​	Julia 数组就是相同数据类型的元素按一定顺序排列的集合，可以是一维数组和多维数字。

- 支持数组数据结构，可以存储一个大小不是固定的，类型可以相同也可以不同的顺序集合；
- 是可变类型集合，用于列表、向量、表格和矩阵；
- 索引键值可以使用整数表示，数组的大小不是固定的；
- 提供了多种函数操作数组；
- 用方括号 `[...]` 指定，多个元素使用逗号 `,` 分隔。

### 2.1. 创建一维数组

```julia
# 一维数组
arr = [1, 2, 3]
# 存储不同类型
arr = [1, "RUNOOB", 2.5, pi]
# 指定存储同一类型
arr = Int64[1, 2, 3]
arr = String["Taobao", "RUNOOB", "GOOGLE"]
# 创建空数组
arr = Int64[]
arr = String[]
```

**注意**：创建的数组可以直接使用索引值来访问，第一个值的索引为 1（不是 0），以此类推，最后一个可以使用 `end` 表示。

### 2.2. 指定数组类型及维度

```julia
Array{type}(undef, dims...)
```

- `undef`：表示数组未初始化；
- `dims`：可以是维度的单多元组，也可以是维度作为可变参数时的一组值，数字表示元素的个数，多个维度使用 `,` 分隔。

**注意**：`undef` 用于设置数组为未初始化为任何已知值，所以输出中可能存在随机数。

### 2.3. 创建二维数组和矩阵

​	可以将数组元素中的逗号 `,` 省略掉或者使用两个分号 `;;` ，创建一个二维数组。

```julia
julia> [1 2 3 4]
1×4 Matrix{Int64}:
 1  2  3  4
```

**注意**：`1x4 Matrix{Int64}` 表示一行四列的矩阵，虽然只有一行，也是二维数组，Julia 只认可列向量，不认可所谓的行向量；添加另外一行，只需要添加一个分号 `;` 。

 	也可以使用冒号 `:` 和空格 ` ` 来实现：

```julia
julia> [1:2 3:4]
2×2 Matrix{Int64}:
 1  3
 2  4
```

​	也可以在方括号 `[]` 中嵌入多个长度相同的一维数组，并用空格分隔来创建二维数组：

```julia
julia> [[1, 2] [3, 4] [5, 6]]
2×3 Matrix{Int64}:
 1  3  5
 2  4  6
```

**注意**：多维数组语法中，`;` 、 `,` 表示换行，` ` 表示换列。

#### 2.4.2. collect() 函数

```julia

```

- `start`：开始值；
- `step`：步长：
- `stop`：结束值。

​	可以生存一个区间范围并指定步长，可以方便 `collect()` 函数调用。

#### 2.4.4. 使用推导式和生成器创建数组


```julia

sum(1/n^2 for n = 1:1000)
```

## 3. 元组

​	Julia 元组与数组类似，都是有序的元素集合，不同之处在于元组的元素不能修改。创建元组，只需要在小括号 `()` 中添加元素，并使用逗号隔开。

### 3.1. 元组命名

#### 3.1.1. 键和值独立命名

​	元组中的键（key）和值（value）可以分开独立命名。

```julia
names_shape = (:corner1, :corner2)
values_shape = ((100, 100), (200, 200))
shape_item2 = NamedTyple{names_shape}(value_shape)

# 访问
shape_item2.corner1
shape_item2.corner2
```

#### 3.1.2. 键和值同时命名

```julia
shape_item = (corner1 = (100, 100), corner2 = (-1, -1))
```

#### 3.1.3. 合并元组

​	可以使用 `merge()` 函数来合并两个已命名的元组。

```julia
merge(tuple1, tuple2)
```

### 3.2. 元组作为函数参数

```julia
function testFunc(x, y, z; a=10, b=20, c=30)
  ...
end

options = (b = 200, c = 300)

testFunc(1, 2, 3; options...)
```

​	如果指定元素在元组后面，会覆盖元组中已有的参数。

```julia
# 不会覆盖
testFunc(1, 2, 3; b = 100_00, options...)
# 会覆盖
testFunc(1, 2, 3; options..., b = 100_00)
```

#### 4.1.1. 溢出行为

​	在 Julia 里，超出一个类型可表示的最大值会导致环绕（wraparound）行为。因此 Julia 的整数算数实际上是模算数的一种形式，反映了现代计算机实现底层算数的特定。

​	在可能有溢出产生的程序中，对最值的边界出现循环进行显示检查时有必要的。否则，推荐使用任意精度算数中的 BigInt 类型作为替代。

#### 4.1.2. 除法错误

​	在以下两种情况下，`rem` 函数和 `mod` 函数会抛出 DivideError 错误，：

- 除以零；
- 除以最小的负数。

### 4.2. 浮点类型

| 类型                                                         | 精度   | 比特数 |
| :----------------------------------------------------------- | :----- | :----- |
| [Float16](https://docs.julialang.org/en/v1/base/numbers/#Core.Float16) | 半精度 | 16     |
| [Float32](https://docs.julialang.org/en/v1/base/numbers/#Core.Float32) | 单精度 | 32     |
| [Float64](https://docs.julialang.org/en/v1/base/numbers/#Core.Float64) | 双精度 | 64     |

**注意**：下划线可以作为数字分隔符。

#### 4.2.1. 浮点数中的零

​	浮点数有两种零，正零和负零。它们相互相等但有着不同的二进制表示，可以使用 `bitstring` 函数来查看。

#### 4.2.2. 特殊的浮点值

| Float16 | Float32 | Float64 | 名称       | 描述                                         |
| :------ | :------ | :------ | :--------- | :------------------------------------------- |
| Inf16   | Inf32   | Inf     | 正无穷     | 一个大于所有有限浮点数的数                   |
| -Inf16  | -Inf32  | -Inf    | 负无穷     | 一个小于所有有限浮点数的数                   |
| NaN16   | NaN32   | NaN     | 不是一个数 | 一个不和任何浮点值（包括自己）相等（==）的值 |

#### 4.2.3. 机器精度

​	大多数实数都无法用浮点数准确地表示，因此有必要知道两个相邻可表示的浮点数之间的距离，它通常被叫做机器精度。

​	Julia 提供了 `eps` 函数，可以给出 1.0 与下一个 Julia 能表示的浮点数之间的差值。

​	两个相邻可表示的浮点数之间的距离并不是常数，数值越小，间距越小，数值越大，间距越大。

​	Julia 也提供了 `nextfloat` 和 `prevfloat` 两个函数，分别返回基于函数的下一更大或更小的可表示的浮点数。

### 4.3. 舍入模式

​	一个数如果没有精确的浮点表示，就必须被舍入一个合适的可表示的值。Julia 所使用的默认模式总是 `RoundNearest` ，指舍入到最接近的可表示的值，这个被舍入的值会使用尽量少的有效位数。

### 4.4. 0 和 1 的字面量

​	Julia 提供了 0 和 1 的字面量函数，可以返回特定类型或所给变量的类型。

| 函数    | 描述                            |
| :------ | :------------------------------ |
| zero(x) | x 类型或变量 x 的类型的零字面量 |
| one(x)  | x 类型或变量 x 的类型的一字面量 |

### 4.5. 类型转换

#### 4.5.1. 强制转换

```julia
T(x)

convert(T, x)
```

- 如果 T 是浮点类型，转换的结果就是最近的可表示值，可能会是正负无穷大；
- 如果 T 是整数类型，当 x 不能由 T 类型表示时，会抛出 `InexactError` 。

#### 4.5.2. 模值转换

```julia
x % T
```

- 将整数 x 转换为整型 T，与 x 模 2^n 的结果一致，其中 n 是 T 的位数。

#### 4.5.3. 舍入函数

​	舍入函数接受一个 T 类型的可选参数。

```julia
# Int(round(x)) 的简写版
round(Int, x)
```

## 5. 复数和有理数

### 5.1. 复数

​	全局变量 `im` 被绑定到复数 i，表示 -1 的主平方根。Julia 允许数值字面量作为数值字面量的系数，这种绑定为复数提供很方便的语法。

```julia
julia> 1+2im
1 + 2im
```

​	所有初等函数在复数上都有完整的定义。

**注意**：

1. 数学函数通常应用于实数就返回实数值，应用于复数就返回复数值；
2. 从变量构建复数是，文本型数字系数记法不再使用，相反地，乘法必须显示地写出。（推荐使用 `complex` 函数构建复数值）

### 5.1. 有理数

​	Julia 有一个用于表示整数精确比值的分数类型。分数通过 `//` 运算符构建。

- 如果一个分数的分子和分母含有公因子，它们会被约分到最简形式且分母非负；
- 整数比值的这种标准化是唯一的，因此分数的相等性可由校验分子与分母都相等来测试；
  - `numerator`：标准化分子；
  - `denominator`：标准化分母；
- 标准算数和比较操作对分数值也有定义；
- 分数可以容易地转换为浮点数；
- Julia 支持构建无穷分数值，但不支持构建 NaN 分数值。

## 9. 正则表达式

​	Julia 具有与 Perl 兼容的正则表达式，输入以前缀 r 开头。

### 9.1. occursin 函数

​	若要检查正则表达式是否匹配某字符串，就用 `occursin()` 函数：

```julia
julia> occursin(r"^\s*(?:#|$)", "not a comment")
false
```

### 9.2. match 函数

​	若要捕获匹配的信息，可以改用 `match()` 函数：

```julia
julia> match(r"^\s*(?:#|$)", "# a comment")
RegexMatch("#")
```

​	若正则表达式与给定字符串不匹配，`match()` 返回 nothing；若正则表达式与给定字符串匹配，`match()` 返回 RegexMatch 对象。

​	当调用 `match()` 时，可以指定开始搜索的索引：

```julia
match(r"[0-9]", "aaaa1aaa2", 1)
```

​	可以从 RegexMatch 对象中提取如下信息：

- `m.match`：匹配的整个子字符串；
- `m.captures`：作为字符串数组捕获的子字符串；
  - 当不匹配时，字符串数组该处返回 nothing；
- `m.offset`：整个匹配开始处的偏移；
- `m.offsets`：作为向量捕获的子字符串的偏移。
  - 当不匹配时，向量该处为 0；

​	让捕获作为数组返回是很方便的，这样就可以用解构语法把它们和局域变量绑定起来。为了方便 ，RegexMatch 对象实现了传递到 `captures` 字段的迭代器方法：

```julia
# m is RegexMatch object
first, second, third = m;
```

​	通过使用捕获组的编号或名称对 RegexMatch 对象进行索引，也可实现对捕获的访问：

```julia
julia> m=match(r"(?<hour>\d+):(?<minute>\d+)","12:45")
RegexMatch("12:45", hour="12", minute="45")

julia> m[:minute]
"45"
```

### 9.3. replace 函数

​	使用 `replace` 时，利用 `\n` 引用第 n 个捕获组和给替换字符串加上 s 前缀，可以实现替换字符串中对捕获的引用。捕获组 0 指的是整个匹配对象，`\g` 指的是对命名捕获组的引用。

```julia
julia> replace("first second", r"(\w+) (?<agroup>\w+)" => s"\g<agroup> \1")
"second first"
```

​	为了明确起见，编号捕获组也可以用 `\g` 进行引用：

```julia
julia> replace("a", r"." => s"\g<0>1")
"a1"
```

#### 11.4.2. for 循环

​	for 循环与 while 循环的一个非常重要的区别是作用域，即变量可见性。如果变量 i 没有在另一个作用域里引用，在 for 循环内，它就只在 for 循环内部可检，在外部和后面均不可见。

​	一般来说，for 循环组件可以用于迭代任意容器，关键字 `in` 或 `∈` 更常用。

​	如果需要提前结束循环，可以使用关键字 `break` 来完成；如果需要结束此次循环，并立刻进入下次迭代，可以使用关键字 `continue` 完成。

​	多个嵌套的 for 循环可以合并到一个外部循环，可以用来创建其迭代对象的笛卡尔积：

```julia

  ...
end
```

**注意**：

1. 此时如果使用 `break` 语句会跳出整个嵌套循环，不仅仅是内层循环；
2. 每次内层循环时，迭代变量会被赋值为当前迭代值，所以对 i 的赋值在接下来的迭代中不可见。

​	可以使用 `zip` 函数在单个循环中同时迭代多个容器：

```julia

  println((j, k))
end
# Variable numbers
for x in zip([0:15], [100:110], [200:210])
  println(x)
end
```

​	使用 `zip` 会创建一个迭代器，它是一个包含传递给它的容器的子迭代器的元组。`zip` 迭代器将按顺序迭代所有子迭代器，在 for 循环的第 ii 此迭代中，选择每个子迭代器的第 ii 个元素。一旦任何子迭代器耗尽，for 循环停止。

### 14.1. open 函数

​	Julia 可以使用 `open()` 函数打开一个文件，该函数文件返回文件句柄：

```julia
open(filename, mode)
```

| mode(模式) | 描述                               | 关键词                         |
| :--------- | :--------------------------------- | :----------------------------- |
| `r`        | read                               | none                           |
| `w`        | 写入、创建、截断                   | `write = true`                 |
| `a`        | 写入、创建、追加                   | `append = true`                |
| `r+`       | 读取, 写入                         | `read = true, write = true`    |
| `w+`       | 读取, 写入、创建、截断             | `truncate = true, read = true` |
| `a+`       | 读取, 写入、创建、写入、创建、追加 | `append = true, read = true`   |

### 14.2. close 函数

​	对文件操作完成后，需要对文件进行关闭操作，使用 `close()` 函数：

```julia
close(file_handle)
```

​	在 Julia 中，建议任何文件处理函数包装在 `do` 语句块中，当该语句块执行完成时，打开的文件将自动关闭。

```julia
open(filename) do file
  # Ope
end
```

### 14.3. read 函数

​	使用 `read()` 函数，可以读取文件的全部内容。

### 14.4. stat 函数

​	`stat()` 函数用于获取文件的信息：

```julia
for n in fieldnames(typeof(stat(filename)))
    println(n, ": ", getfield(stat(filename),n))
end
```

###  14.5. abspath 函数

​	用于获取文件的绝对路径，可以映射列表中：

```julia
stat(pathname)
```

## 15. 元编程

​	Julia 可以把自己的代码表示为语言中的数据结构，这样可以编写操纵程序的程序。

### 15.1. 程序表示

​	Julia 提供了以个 Meta 类，其中可以用 `Meta.parse(str)` 来对一个字符串进行解析。

```julia
prog = "1 + 1"
ex1 = Meta.parse(prog)
```

#### 15.1.1. Expr 对象

​	用 `typeof(e1)` 返回 Expr 。Expr 对象包含两个部分，`head` 和 `args` 属性。

```julia
julia> ex1.head
:call

julia> ex1.args
3-element Vector{Any}:
	:+
 1
 1
```

​	表达式也可以直接用 Expr 构造。

```julia
ex2 = Expr(:call, :+, 1, 1)
```

​	Expr 对象也可以嵌套。

#### 15.1.2. 符号

​	可以通过冒号 `:` 前缀运算符存储一个未计算但已解析的表达式。

```julia
julia> :(100-50)
:(100 - 50)
```

### 15.2. 执行表达式

​	表达式解析后，可以使用 `eval()` 函数来执行：

```julia
eval(Expr)
```

### 15.3. 抽象语法树（AST）

​	抽象语法树（AST）是一种结构，是源代码语法结构的一种抽象表示。以树状的形状表现变成语言的语法结构，树上的每个节点都表示源代码中的一种结构。

```julia
julia> dump(:(1 * cos(pi/2)))
Expr
   head: Symbol call
   args: Array{Any}((3,))
      1: Symbol *
      2: Int64 1
      3: Expr
         head: Symbol call
         args: Array{Any}((2,))
            1: Symbol cos
            2: Expr
               head: Symbol call
               args: Array{Any}((3,))
                  1: Symbol /
                  2: Symbol pi
                  3: Int64 2
```

### 15.4. 插值

​	Julia 允许将字面量或表达式插入到被引用的表达式中，表达式插值由前缀 `$` 表示。

```julia
julia> ex = :(a in $:((1,2,3)) )
:(a in (1, 2, 3))
```

​	在表达式插值中使用 `$` 是有意让人联想到字符串插值和命令插值。表达式插值使得复杂 Julia 表达式的程序化构造变得方便和易读。

### 15.5. 宏

​	宏提供了一种机制，可以将生成的代码包含在程序的最终主体中。宏将一组参数映射到返回的表达式，并且生成的表达式被直接编译，而不需要运行时调用 `eval()` 。宏参数可能包括表达式、字面量和符号。

​	宏在 Julia 语法中有一个专门的字符 @，紧接着是其使用的 `macro Name … end` 形式来声明的唯一的宏名。编译器会把所有的宏替换为表达式。

​	可以使用函数 `macroexpand` 查看引用的返回表达式：

```julia
julia> ex = macroexpand(Main, :(@sayhello("human")) )
:(Main.println("Hello, ", "human"))
```

​	其中，`Main` 表示宏的作用域。也可以使用宏 `@macroexpand` 更方便的查看返回表达式。

```julia
julia> @macroexpand @sayhello "human"
:(println("Hello, ", "human"))
```
